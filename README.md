# Student Portfolio

A responsive personal portfolio website created to showcase my profile, skills, projects, and interests as an AI & Data Science student.

## 📌 About the Project

This project is a personal student portfolio designed to present my academic background, technical skills, projects, and areas of interest in a simple and organized way.

The website provides a central place to learn about me and explore the work I have done.

## ✨ Features

- Personal introduction
- About Me section
- Skills and technologies
- Projects showcase
- Education / academic information
- Contact section
- Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
